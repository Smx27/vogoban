# Local graph visualization

`vogoban graph [path]` opens an interactive local architecture graph from the current repository's `.vogoban/graph.db`. The server binds only to `127.0.0.1`; no account, telemetry, source upload, or hosted service is required. The client is bundled locally with React Flow, so node dragging, pan/zoom, minimap and keyboard-friendly graph controls stay in the repository-local workflow.

The Architecture, Dependencies, Infrastructure, Messaging, and Frontend views are projections of the same RepositoryGraph queried by the CLI and MCP. Search, filters, node details, relationships, provenance, bounded neighborhood expansion, and impact use actual stored graph facts. The default view intentionally favors architectural entities rather than rendering every class or method.

The workspace uses a dark, restrained visual system with a repository sidebar, type filters, and a collapsible inspector. React Flow supplies graph interaction; Dagre positions small connected components from stored edge direction. Components with more than 160 entities use a deterministic compact force layout so large repository hubs do not become a tall, unreadable strip. Layout changes positions only; it never adds relationships. Unconnected entities remain visible without adding inferred edges.

Choose **Show all relationships** to load every relationship stored for the repository and its actual endpoint entities, including source-level types, methods and files. There is no 5,000-row query cutoff. The coverage strip reports the stored relationship count, what was loaded, and any missing endpoint IDs. Missing endpoints are diagnostics, not fabricated nodes. Type filters explicitly reduce what is visible; clear them to restore all loaded entities and relationships. **Use Architecture projection** returns to progressive architectural exploration. MetaGraph stays a separate graph and has its own complete mode and endpoint inspection.

Search favors architectural entities before lower-level source files. Select a result or a node to inspect inbound and outbound relationships. **Focus** narrows the canvas to its direct neighborhood; **Expand** adds neighbors to the current view without a silent 120-entity display cap. **Reset view** returns to the original projection or complete graph, depending on the selected mode. Edge labels can be enabled globally; relationships touching the selected node show their labels automatically. Parallel and reciprocal relationships have separate curved paths, and self-relationships have visible loops. Relationship strokes adapt to zoom so connections remain visible when fitting a large graph. Selecting an entity does not fade unrelated edges.

The inspector exposes source filenames, line numbers, analyzers, evidence levels, confidence, and deterministic impact results. Its overview's “most connected” entries count only relationships in the current view, not repository-wide centrality or a risk score.

Switch to **List** for keyboard-accessible textual exploration or **Edges** to inspect relationships with their actual source and target names, evidence and provenance. The Edges list uses 100-row pages; pagination does not limit the underlying graph. On smaller screens, navigation becomes an explicit drawer and entity details use a bottom panel. Focus indicators and reduced-motion preferences are respected. All client assets and icons are served locally; the UI does not fetch fonts or other assets from external services.
