# Release reports

Historical audit records kept for traceability. They describe the state of the code at the time of each gate, including measured results and accepted limitations; file paths mentioned inside them (for example `docs/runbook.md`) refer to the documentation layout of that time. For current behaviour, use the rest of the documentation.
